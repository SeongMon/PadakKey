# PadakKey 아이콘 작업 폴더

- `Candidates/`: 디자인 초안과 후보 이미지
- `Custom/`: 앱에서 사용할 사용자 아이콘을 넣는 폴더

권장 형식은 배경이 투명한 정사각형 PNG입니다. 메뉴 막대의 작은 크기에서도 식별할 수 있도록 굵은 윤곽과 단순한 형태를 사용하세요.

앱 톱니바퀴 → **아이콘 선택**에서 파닥이는 참새 / 조는 참새를 고를 수 있습니다.
**애니메이션**을 끄면 선택한 아이콘의 첫 프레임으로 멈춥니다.

**아이콘 추가…**에서 PNG 또는 GIF를 가져오세요. 앱이 `~/Library/Application Support/PadakKey/Icons`에 복사하므로 원본을 이동해도 유지됩니다. **아이콘 폴더 열기**로 저장 위치를 열 수 있고, 해당 폴더에 넣은 PNG/GIF도 다음 팝오버 열기 때 목록에 표시됩니다.
GIF는 애니메이션을 켰을 때만 움직입니다. 최대 10MB / 4096px / 120프레임, 전체 프레임 합계 3,200만 픽셀까지 지원합니다. 투명 배경과 여백이 적은 작은 이미지를 권장합니다.

- `Sparrow/`: 파닥임 원본 및 미리보기
- `Sparrow-Doze/`: 무늬 있는 참새의 졸음 원본 및 미리보기
- `Sparrow-Sleep/`: 사용하지 않는 이전 초안
- `Custom/`: 저장소의 작업용 폴더이며 앱의 실제 저장 위치와는 별개입니다.
